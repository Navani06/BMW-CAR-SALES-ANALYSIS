# BMW-CAR-SALES-ANALYSIS
BMW car sales analysis using Power BI to visualize sales trends, model performance, and key business insights through interactive dashboards.
This project presents an interactive Power BI dashboard for analyzing BMW car sales data.The dashboard highlights key sales trends, revenue performance, and model-wise analysis.Power BI visuals and KPIs are used to simplify complex sales data.DAX measures enable deeper insights into growth and performance metrics.
The analysis supports data-driven decision-making through clear and dynamic reporting.
